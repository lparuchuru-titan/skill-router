# Review a pull request

Load this skill before commenting on a diff.

1. Read the change as a reviewer: what behavior moved, and what can break.
2. Call out security issues, missing tests, and behavior changes that the description does not mention.
3. Prefer a short list of concrete findings over a style tour.
